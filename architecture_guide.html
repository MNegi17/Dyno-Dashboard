🌙 Midnight Rollover Engine

When the clock turns 12:01 AM IST:

  1. The worker runs a full 24-hour retrospective query for yesterday (12:01 AM to 11:59:59 PM IST).
  2. Captures all late-night orders and permanently locks and seals yesterday's dataset in Supabase (e.g., 896 units).
  3. Shifts the live ingestion window to target today's date ([REALTIME_SYNC] 13 Aug 2026).

⚡ Sub-300ms Instant Refresh

When the user clicks "Refresh" in the browser:

  1. Queries Supabase directly in < 300ms and injects data straight into React state.
  2. Updates the "Last updated" time box and triggers the 5-minute cooldown countdown (Refresh (4:59)).
  3. Dispatches a background ping to Railway non-blockingly without delaying the user.

⚙️ 3. Deep Dive: Core Engineering Logics

💰 Dynamic Multi-Channel Pricing Engine

Marketplaces like Ajio, Flipkart, and Amazon Cocoblu return wholesale transfer prices instead of consumer Selling Prices. We calculate consumer SP dynamically based on Myntra's real-time discount rate:

MyntraDiscount_i = 1 - (SP_i / MRP_i)
AvgMyntraDiscount = (1 / N) * Σ (MyntraDiscount_i)
SP_Ajio/Cocoblu/Flipkart = MRP - (MRP * AvgMyntraDiscount)

🏷️ 52,900+ Master SKU Directory & Prefix Deductor

Performs instant in-memory catalog enrichment. If an unmapped SKU is purchased, a deterministic prefix deduction engine categorizes it instantly:

Footwear: TGCAFS, TBCABS, SLIDES, MOULDS
Apparel: JEANS (JN), SHIRT (SH), TSHIRT (TS), DRESS (DR)
Accessories: CAP, SOCKS, BAG

🔄 Full Auto-Pagination Traversal

Uniware limits search results to 500 orders per API call. We engineered an autonomous pagination traversal loop:

while (has_more):
  fetch(displayStart, displayLength=500)
  displayStart += 500
  if fetched_count >= totalRecords: break

🚀 Multithreaded Concurrency Pool

Using Python's concurrent.futures.ThreadPoolExecutor(max_workers=8), orders are fetched in parallel batches, reducing network round-trip time from 200s to 15s (85% reduction).
